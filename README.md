# إكس أو — ثلاثة أحجار أونلاين

لعبة عربية للهاتف والمتصفح: لكل لاعب 3 أحجار. بعد أن يضع اللاعب أحجاره الثلاثة، يختار مربعًا فارغًا لوضع الحجر التالي، ثم يختار بنفسه أي حجر من أحجاره الثلاثة ليحذفه. أول لاعب يصنع ثلاثة أحجار متتالية يفوز.

## ما الذي يتضمنه المشروع؟
- واجهة عربية مناسبة لشاشة الهاتف.
- مطابقة لاعبين عشوائيًا عبر الإنترنت.
- إنشاء غرفة خاصة برمز من 5 أحرف/أرقام ومشاركة الرمز مع صديق.
- الانضمام إلى غرفة خاصة باستخدام الرمز.
- التحقق من الأدوار والحركات على الخادم.
- إعادة مباراة بموافقة اللاعبين.
- يمكن تثبيتها على شاشة الهاتف الرئيسية كـ PWA بعد نشرها على HTTPS.

## التشغيل على الكمبيوتر للاختبار
يتطلب Node.js 18 أو أحدث.

```bash
npm install
npm start
```

ثم افتح `http://localhost:3000`.

## جعلها أونلاين على الإنترنت
هذا المشروع يحتاج إلى نشر الخادم على خدمة تدعم Node.js وWebSockets. مثال عملي:
1. ارفع مجلد المشروع إلى مستودع GitHub.
2. أنشئ Web Service على Render واربطه بالمستودع.
3. أمر البناء: `npm install`
4. أمر التشغيل: `npm start`
5. بعد النشر افتح رابط HTTPS الذي تمنحك إياه الخدمة.

عندها يستطيع لاعبان فتح الرابط من هاتفين مختلفين والضغط على «ابحث عن لاعب». لا توجد حسابات أو كلمات مرور في هذه النسخة الأولية.

## تثبيتها على أندرويد
بعد نشر اللعبة على HTTPS، افتح الرابط في Chrome على أندرويد، ثم قائمة ⋮ واختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق» إذا ظهر الخيار.

## ملاحظات
- هذه نسخة أولية قابلة للتطوير وليست APK جاهزًا.
- لا يوجد نظام حسابات أو حفظ إحصائيات في هذه النسخة.
- يجب إبقاء الخادم يعمل كي يتمكن اللاعبون من الاتصال.


## نشر سريع على Render
أضف المشروع إلى مستودع GitHub ثم افتح لوحة Render واختر New > Blueprint، وحدد المستودع الذي يحتوي على `render.yaml`. راجع الإعدادات ثم أنشئ الخدمة. إذا لم تستخدم Blueprint، اختر New > Web Service وحدد المستودع، واجعل:
- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`
- Plan: Free (إذا كان متاحًا لحسابك)

انتظر حتى تصبح الخدمة Live، ثم افتح رابط `onrender.com`. الخادم يستعمل `PORT` ويستمع على `0.0.0.0` ويدعم WebSockets. قد تدخل الخدمة المجانية في وضع السكون بعد فترة من عدم النشاط، وقد يتأخر أول اتصال عند إيقاظها.
